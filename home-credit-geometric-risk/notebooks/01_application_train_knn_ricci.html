🎯 Objetivo

Construir um grafo de similaridade entre clientes a partir da tabela application_train, calcular curvatura de Ricci nas conexões e gerar as primeiras features geométricas para uso futuro em modelagem de risco de crédito.

  • ⚙️ Ações realizadas

    • leitura da tabela application_train da camada bronze
    • seleção inicial de variáveis numéricas
    • tratamento simples de valores ausentes
    • padronização das variáveis
    • construção de grafo KNN
    • cálculo de Ollivier-Ricci Curvature
    • geração de features geométricas por nó

  • 🧠 Justificativa técnica

  • A hipótese central do projeto é que a estrutura geométrica local de um grafo de similaridade entre clientes pode revelar padrões latentes de risco não capturados totalmente pelo espaço tabular tradicional ?

  • ✅ Resultados esperados

    • subgrafo KNN dos clientes
    • curvatura calculada nas arestas
    • tabela de features geométricas por cliente
    • base pronta para comparação com baseline tabular

📌 NearestNeighbors (algoritmos de Vizinhos Mais Próximos)

  • NearestNeighbors implementa o aprendizado não supervisionado de vizinhos mais próximos.
    • Ele atua como uma interface uniforme para três algoritmos diferentes de vizinhos mais próximos:
      • BallTree,
      • KDTree,
      • e um algoritmo de força bruta baseado em rotinas do sklearn.metrics.pairwise.
    • A escolha do algoritmo de busca de vizinhos é controlada pela palavra-chave 'algorithm', que deve ser um dos seguintes valores: ['auto', 'ball_tree', 'kd_tree', 'brute'].
    • Quando o valor padrão 'auto' é passado, o algoritmo tenta determinar a melhor abordagem a partir dos dados de treinamento.
    • Para uma discussão sobre os pontos fortes e fracos de cada opção, consulte Nearest Neighbor Algorithms.
    • https://scikit-learn.org/stable/modules/neighbors.html#nearest-neighbor-algorithms
  • Aviso
    • Em relação aos Nearest Neighbor Algorithms, se dois vizinhos tiverem distâncias idênticas, mas rótulos diferentes, o resultado dependerá da ordem dos dados de treinamento.

✔️ 09 - Converter KNN em grafo NetworkX

node_ids = graph_sample["SK_ID_CURR"].to_list()
target_map = dict(zip(
    graph_sample["SK_ID_CURR"].to_list(),
    graph_sample["TARGET"].to_list()
))

# coleta todas as distâncias válidas do KNN (sem o próprio ponto)
all_knn_distances = distances[:, 1:].flatten()

global_min_dist = float(np.min(all_knn_distances))
global_max_dist = float(np.max(all_knn_distances))

def normalize_distance(d, dmin, dmax, eps=1e-3):
    """
    Normaliza distância para uma faixa estável [eps, 1.0].
    Preserva ordem relativa e evita underflow numérico.
    """
    if dmax == dmin:
        return 1.0
    return eps + (1.0 - eps) * ((d - dmin) / (dmax - dmin))

G = nx.Graph()

# adiciona nós
for sk_id in node_ids:
    G.add_node(sk_id, target=target_map[sk_id])

# adiciona arestas com peso normalizado
for row_idx, neighbors in enumerate(indices):
    source_id = node_ids[row_idx]

    for pos in range(1, len(neighbors)):  # ignora o próprio ponto
        neighbor_idx = neighbors[pos]
        target_id = node_ids[neighbor_idx]

        raw_distance = float(distances[row_idx][pos])
        norm_distance = normalize_distance(
            raw_distance,
            global_min_dist,
            global_max_dist
        )

        if source_id != target_id:
            # Mantém informação geométrica da distância
            # "normalizar distâncias para [1e-3, 1.0]" evita o problema dos pesos absurdamente pequenos
            # continua coerente com o projeto
            G.add_edge(source_id, target_id, weight=norm_distance, raw_distance=raw_distance)
            
            # =====================================================================
            # Sem peso nenhum no grafo, só para validar a pipeline
            # Isso transforma o experimento em KNN não ponderado.
            # É menos refinado, mas muito bom para um primeiro ciclo.
            # =====================================================================
            # G.add_edge(source_id, target_id, weight=norm_distance, raw_distance=raw_distance)

✔️ 13 - Gerar features geométricas por nó

node_curvature_rows = []

for node in G_ricci.nodes():
    incident_curvatures = []

    for neighbor in G_ricci.neighbors(node):
        edge_data = G_ricci.get_edge_data(node, neighbor)
        curv = edge_data.get("ricciCurvature")
        if curv is not None:
            incident_curvatures.append(curv)

    if incident_curvatures:
        node_curvature_rows.append({
            "SK_ID_CURR": node,
