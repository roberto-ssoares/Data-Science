🎯 Objetivo

  • Comparar o desempenho de modelos de classificação de risco de crédito usando:
    1. apenas variáveis tabulares tradicionais
    2. variáveis tabulares enriquecidas com features geométricas derivadas do grafo KNN com curvatura de Ricci
  • ⚙️ Ações realizadas
    • leitura da tabela application_train
    • leitura das features geométricas geradas no notebook anterior
    • construção de dataset baseline
    • construção de dataset enriquecido
    • treinamento e avaliação de modelos
    • comparação de métricas preditivas
  • 🧠 Justificativa técnica
    • A hipótese central é que as features geométricas capturam estrutura relacional local entre clientes e podem agregar sinal ao espaço tabular tradicional de crédito ?
  • ✅ Resultados esperados
    • benchmark baseline
    • benchmark tabular + geométrico
    • comparação objetiva de desempenho
    • evidência inicial do valor da abordagem geométrica

✔️ 11 - Função KS

def ks_statistic(y_true, y_score):
    """
    Calcula KS a partir das curvas TPR e FPR.
    """
    fpr, tpr, _ = roc_curve(y_true, y_score)
    ks = np.max(tpr - fpr)
    return float(ks)

✔️ 12 - Função de avaliação

def evaluate_model(model, X_train, X_test, y_train, y_test, model_name, scenario_name):
    model.fit(X_train, y_train)

    if hasattr(model, "predict_proba"):
        y_score = model.predict_proba(X_test)[:, 1]
    else:
        y_score = model.decision_function(X_test)

    result = {
        "scenario": scenario_name,
        "model": model_name,
        "roc_auc": roc_auc_score(y_test, y_score),
        "avg_precision": average_precision_score(y_test, y_score),
        "ks": ks_statistic(y_test, y_score),
    }

    return result, y_score

✔️ 13 - Pipeline dos modelos

numeric_pipe_scaled = Pipeline(steps=[
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler()),
])

numeric_pipe_tree = Pipeline(steps=[
    ("imputer", SimpleImputer(strategy="median")),
])

def make_logistic_pipeline(feature_list):
    return Pipeline(steps=[
        ("prep", ColumnTransformer(
            transformers=[("num", numeric_pipe_scaled, feature_list)],
            remainder="drop"
        )),
        ("model", LogisticRegression(
            max_iter=1000,
            random_state=42,
            class_weight="balanced"
        ))
    ])

def make_rf_pipeline(feature_list):
    return Pipeline(steps=[
        ("prep", ColumnTransformer(
            transformers=[("num", numeric_pipe_tree, feature_list)],
            remainder="drop"
        )),
        ("model", RandomForestClassifier(
            n_estimators=300,
            max_depth=None,
            min_samples_leaf=5,
            random_state=42,
            n_jobs=-1,
            class_weight="balanced_subsample"
        ))
    ])

def make_lgbm_pipeline(feature_list):
    return Pipeline(steps=[
        ("prep", ColumnTransformer(
            transformers=[("num", numeric_pipe_tree, feature_list)],
            remainder="drop"
        )),
        ("model", LGBMClassifier(
            n_estimators=300,
            learning_rate=0.05,
            num_leaves=31,
            subsample=0.8,
            colsample_bytree=0.8,
            random_state=42,
            class_weight="balanced",
            verbose=-1
        ))
    ])

🧠 Conclusão da Etapa

  • Este notebook avaliou o impacto da incorporação de features geométricas
    • derivadas de um grafo KNN com curvatura de Ricci
    • em modelos de classificação de risco de crédito.
  • 📊 Resultados principais
    • A Logistic Regression apresentou melhora consistente em todas as métricas (ROC-AUC, KS e Average Precision) ao incorporar features geométricas.
    • Modelos baseados em árvores (Random Forest e LightGBM) não apresentaram ganho consistente, sugerindo possível redundância ou necessidade de refinamento das features geométricas.
    • Métricas geométricas como geom_curvature_std, geom_curvature_min e geom_curvature_mean apareceram entre as variáveis mais importantes.
  • 🔍 Interpretação técnica
    • Os resultados indicam que:
      • A geometria do grafo captura estrutura relacional entre clientes que não está explicitamente representada no espaço tabular.

      • A variabilidade da curvatura (instabilidade estrutural local) pode estar associada a perfis de risco diferenciados.

      • Curvatura de Ricci pode ser operacionalizada em dados reais
