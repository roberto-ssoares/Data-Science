✔️ 1. Contexto do Projeto

  • A preparação para uma certificação técnica normalmente é conduzida por listas de tópicos, vídeos, cursos e simulados.

    • Neste projeto, a proposta é transformar essa jornada em um Knowledge Graph evolutivo.

  • O grafo será usado para mapear:

    • domínios oficiais do exame;
    • tópicos técnicos;
    • relações de pré-requisito;
    • recursos de estudo;
    • notebooks práticos;
    • sessões de estudo;
    • lacunas de conhecimento;
    • insights;
    • progresso semanal.

  • Esse projeto combina preparação para certificação com modelagem semântica, engenharia de dados, visualização em grafos e narrativa de portfólio.

✔️ 2. Enquadramento CRISP-DM+

  • Neste projeto, usamos uma extensão do CRISP-DM tradicional com uma etapa anterior chamada:
    • Etapa 0 — Domain Understanding via Ontology + BLM + Semantic Clustering
  • Essa etapa tem como objetivo compreender o domínio antes da modelagem dos dados.
  • No contexto deste projeto:
    • Ontologia define entidades e relacionamentos do conhecimento.
    • BLM — Business Language Model padroniza a linguagem usada para falar sobre certificação, estudo, prática e progresso.
    • Cluster Semântico agrupa tópicos tecnicamente próximos.
    • Taxonomia organiza o conhecimento em hierarquias compreensíveis.

✔️ 5. Relacionamentos iniciais

  • Os relacionamentos definem a semântica do Knowledge Graph.
  • Eles devem responder perguntas como:
    • Quais tópicos pertencem a cada domínio?
    • Quais tópicos são pré-requisitos de outros?
    • Quais notebooks praticam cada tópico?
    • Quais erros estão associados a quais assuntos?
    • Como meu domínio evoluiu ao longo das semanas?

✔️ 7. Modelo inicial de progresso

  • O KG acompanhará dois tipos de evolução:
  • Confidence Score
    • Mede a percepção subjetiva de segurança sobre o tópico.
  • Mastery Score
    • Mede evidência prática associada ao tópico.
  • Essa separação é importante porque um tópico pode parecer conhecido, mas ainda não ter evidência prática suficiente.

progress_scale = pd.DataFrame(
    [
        {"score": 0.00, "confidence_meaning": "Não conheço", "mastery_meaning": "Sem evidência prática"},

✔️ 8. Primeira leitura estratégica

  • Neste momento, os tópicos com maior peso e maior impacto prático são:
    • Development and Ingestion
    • Data Processing & Transformations
    • Productionizing Data Pipelines
  • Esses domínios serão priorizados porque concentram a maior parte do exame e também geram evidências fortes para portfólio.

priority_view = (
    exam_domains
    .sort_values(by="weight_pct", ascending=False)
    .assign(
        strategic_focus=lambda df: df["weight_pct"].apply(
            lambda x: "primary" if x >= 18 else "support"
        )
    )
)
