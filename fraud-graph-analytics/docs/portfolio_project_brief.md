# Fraud Graph Analytics

## Prevenção a Fraudes Transacionais com Knowledge Graph, Regras Explicáveis e Graph Analytics

### Problema de Negócio

Fraudes transacionais podem surgir a partir de relações indiretas entre contas, dispositivos, beneficiários, IPs e padrões de movimentação. O projeto propõe um MVP analítico para detectar e explicar sinais de risco usando regras e grafos.

### Solução Proposta

O MVP combina dados sintéticos, motor de regras antifraude, modelagem em Knowledge Graph, algoritmos de centralidade/comunidades e um score final explicável.

### Metodologia

CRISP-DM+ com Ontologia, Business Language Model, Taxonomia de Fraudes e Graph Analytics.

### Principais Entregáveis

- Base sintética transacional
- Motor de regras antifraude explicável
- Modelo de Knowledge Graph para Neo4j
- Scripts Cypher
- Algoritmos de grafo
- Fraud Risk Score final
- Explicações textuais por alerta
- Relatórios executivos de portfólio

### Stack Técnica

- Python
- Pandas
- NumPy
- Faker
- NetworkX
- Neo4j
- Cypher
- Plotly
- CRISP-DM+

### Posicionamento de Portfólio

Projeto de portfólio sênior para demonstrar capacidade de conectar negócio, dados, regras, grafos, explicabilidade e empacotamento executivo em um caso aplicado a prevenção a fraudes.
