# Databricks Credit Risk Lakehouse

Projeto de preparação para a certificação Databricks Certified Data Engineer Associate.

## Objetivo

Construir um pipeline analítico em arquitetura Lakehouse para dados de crédito, utilizando Databricks, Spark SQL, PySpark, Delta Lake, Workflows e práticas de governança.

## Tecnologias
